# Security LernApp

Lern-App für die **Sachkundeprüfung nach § 34a GewO**, aufgebaut wie eine Führerschein-Lern-App.

- 9 Sachgebiete mit Lernkapiteln
- über 350 eigene Übungsfragen mit Erklärung und Paragraph
- Fortschritt pro Frage (grau → rot → gelb → grün), Fehler werden bevorzugt wiederholt
- Prüfungssimulation: 82 Fragen, 120 Minuten, Auswertung pro Sachgebiet
- Eigene Fragen hinzufügen, Fragen markieren, Backup
- Installierbar auf dem Handy (PWA), funktioniert offline

## Online stellen mit GitHub Pages
1. Neues Repository anlegen (z. B. `security-lernapp`).
2. Alle Dateien dieses Ordners hochladen.
3. **Settings → Pages → Branch: `main` / Ordner `/ (root)` → Save**.
4. Nach 1–2 Minuten ist die App unter `https://DEINNAME.github.io/security-lernapp/` erreichbar.

Hinweis: Die Fragen sind selbst formuliert auf Grundlage der Gesetzestexte. Ohne Gewähr – im Zweifel gilt der aktuelle Gesetzestext.
